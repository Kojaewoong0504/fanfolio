# Inventory Source Identity Design

## Goal

팬 컬렉션의 출처 선택 영역이 보상 이미지가 아니라 출처의 정체성을 표현하도록 만들고, 아티스트 보상과 전체 레벨 보상을 분리한다.

## Source contract

- 아티스트 출처는 `artistLogoUrl` 메타데이터만 로고로 사용한다.
- 로고가 없거나 불러오지 못하면 아티스트명의 첫 글자를 표시한다.
- 전체 레벨 출처는 팬폴리오 공통 별 심볼을 사용한다.
- 보상 이미지는 아이템 카드에서만 사용한다.
- 출처 탭은 사용자가 실제로 획득한 아이템이 있는 경우에만 생성한다.

## Preview data

- 드림스케이프 시즌 배지, 별빛 프로필 프레임, 응원 메시지 배경은 드림스케이프 출처로 유지한다.
- 랜덤 카드 뽑기권은 `scope: global`을 사용해 전체 레벨 출처로 이동한다.
- 포인트는 기존 마이 화면에서 관리하므로 팬 컬렉션에 중복 표시하지 않는다.

## Interaction and accessibility

- 출처 탭의 선택, 개수, 상태 필터 동작은 유지한다.
- 로고는 장식 이미지로 처리하고, 폴백 문자와 공통 심볼도 동일한 원형 영역에 표시한다.
- 출처 전환 시 현재처럼 상태 필터와 안내 메시지를 초기화한다.

## Verification

- 소스 회귀 테스트로 보상 이미지가 출처 썸네일에 사용되지 않는지 확인한다.
- 미리보기 데이터에서 드림스케이프 3개, 전체 레벨 1개가 생성되는지 확인한다.
- 전체 테스트, 빌드, 린트와 브라우저 미리보기를 검증한다.
