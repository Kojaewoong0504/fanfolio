# Fan Pulse 브랜드 에셋 설계

## 목표

Fanfolio의 기존 임시 `F` 박스와 단순 SVG favicon을 교체하고, K-POP 팬 커뮤니티의 응원봉·빛·실시간 연결감을 표현하는 실제 이미지 기반 아이콘을 적용한다.

## 결정

- 브랜드 방향은 `Fan Pulse`로 확정한다.
- 작은 화면에서 읽히지 않는 문자는 생성 이미지 안에 넣지 않는다.
- 생성 이미지는 앱 아이콘과 favicon의 공통 원본으로 사용한다.
- `FANFOLIO` 워드마크는 생성 이미지가 아니라 UI 텍스트로 렌더링해 선명도와 접근성을 보장한다.
- 아이콘의 시각 언어는 딥 퍼플, 일렉트릭 블루, 아쿠아 민트, 마젠타 포인트를 사용한다.

## 적용 범위

1. `frontend/public/fanfolio-app-icon.png`: 생성된 정사각 앱 아이콘 원본
2. `frontend/public/favicon.png`: favicon 파생 파일
3. `frontend/index.html`: PNG favicon과 Apple touch icon, theme color 연결
4. 로그인 화면: 기존 문자 `F` 박스 대신 생성 아이콘과 워드마크 사용
5. 앱 헤더/설정 프로필: 기존 임시 브랜드 표현을 생성 아이콘으로 교체

## 생성 이미지 제약

- 정사각형, 중앙 배치, 충분한 여백
- 아이콘 단독으로도 식별 가능
- 글자, 숫자, 워터마크, 사람 얼굴, 실제 아티스트 이미지 제외
- 복잡한 배경과 얇은 선은 피하고, 16px favicon에서도 형태가 유지되도록 단순한 덩어리와 명확한 대비를 사용

## 검증

- 생성 결과를 직접 확인한다.
- favicon 및 앱 화면에서 실제 렌더링을 확인한다.
- frontend lint와 build를 실행한다.
- 아이콘 파일이 빌드 산출물에 포함되는지 확인한다.
