# 크리스털 포일 — 로컬 구현과 검증

## 목표와 현재 경계

2026-09-03 12:59:54 첨부 시안의 불규칙한 무지개 결정면, 가는 연결선,
미세 입자와 긴 별빛을 실시간으로 합성한다. 이미지 생성 시안을 카드 위에
붙이는 방식은 사용하지 않는다. **시안과 픽셀 단위로 같은 결과는 아니다.**
결정면의 배치와 빛 번짐 질감은 여전히 다르다.

## 구현

- `builder_app/foil-renderer.js`: 공유 WebGL2 렌더러. 결정면 방향/연결선/별빛
  맵은 코드로 생성하고, 각도와 광택/번짐/입자 값을 셰이더에 전달한다.
- `builder_app/app.js`: 기존 단순 스트라이프 셰이더를 공유 렌더러로 교체.
  선택지의 작은 미리보기도 같은 렌더러가 만든 출력이다.
- `builder_app/foil-review.html`: 회색 바탕과 기존 인물 사진에 동일한 효과를
  적용하는 비교 화면. 흰 프레임과 문구는 비교용 장식이며 표면 효과가 아니다.
- 연속 자동 재생 없이 입력/리사이즈에 맞춰 다시 그린다. DPR은 1.5로 제한한다.
  제거된 카드의 WebGL 자원과 이벤트/옵저버를 정리한다.
- 홈의 초안 재개 버튼은 복원된 로컬 편집 상태를 열도록 수정했다.

## 직접 확인한 내용

- Codex 실제 브라우저에서 여섯 패턴을 각각 선택해 화면을 캡처/확인했다.
- 좌우 각도 버튼에서 결정면의 반사 위치가 달라졌다.
- 효과 끄기 및 스튜디오 광택 0에서 표면 효과가 사라졌다.
- 스튜디오 특수효과 탭의 빈 카드에서 파일 선택창을 통해 기존 샘플 사진을
  업로드하고, 같은 결정 포일이 표시되는 것을 확인했다.
- 광택 72%, 입자 100% 조작에서 실제 출력 변화가 확인됐다.
- 해당 스튜디오 검증 시 브라우저 오류/경고 로그는 없었다.
- builder 테스트 86개 통과. 이 테스트 수치는 시안과의 시각적 동일성을
  증명하지 않는다. JS 문법 검사와 변경 파일 공백 검사도 별도로 실행했다.

## 미검증/남은 사항

- iPhone 실제 기기 센서, GPU 프레임 시간, 저사양 기기의 장시간 성능.
  비교 화면의 CPU 제출 시간은 GPU 렌더링 시간/FPS가 아니다.
- 팬앱 렌더러 통합과 운영 배포는 이번 변경에 포함하지 않는다.
- '배경' 적용 범위는 근사 영역이며 AI 인물 마스크를 사용하지 않는다.
- 서버 저장 전 사진은 blob URL을 로컬 초안에서 제외하는 기존 경로 때문에
  새로고침 후 유지되지 않는 현상을 확인했다. 효과 값은 복원되지만 사진
  복원 문제는 별도 영속 저장 개선이 필요하다. 서버 초안 저장 검증은 하지 않았다.
