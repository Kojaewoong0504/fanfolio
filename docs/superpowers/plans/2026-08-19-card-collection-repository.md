# 카드 컬렉션 저장소 구현 계획

1. 보관함과 전용 카드 저장소의 라우팅·진입 계약을 테스트로 고정한다.
2. 관리자 지정 컬렉션 그룹, 복수 카드팩, 팩별 카드 슬롯 목업 데이터를 추가한다.
3. `/collection/cards`와 개발 미리보기 `?preview=card-collection`을 연결한다.
4. 보관함 최근 카드에서 정렬·필터와 인라인 관리 영역을 제거하고 전용 화면 진입만 남긴다.
5. 선택 시안에 맞춘 4열 카드 도감과 반응형 스타일을 추가한다.
6. 집중 테스트, 전체 테스트, 빌드, 린트와 브라우저 시각·상호작용 QA를 수행한다.
