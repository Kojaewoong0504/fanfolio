# 마일스톤 상태 및 스크롤 인디케이터 설계

## 목표

팬 레벨 마일스톤에서 보상 상태를 정확하게 표시하고, 카드 레일의 실제 가로 스크롤 위치를 하단 인디케이터에 동기화한다.

## 범위

- 완료된 보상은 완료 아이콘을 표시한다.
- 현재 레벨 보상이 아직 해금되지 않았다면 현재 배지와 잠금 아이콘을 함께 표시한다.
- 이후 레벨 보상은 잠금 아이콘을 표시한다.
- 잠금 표시는 프로젝트가 사용하는 아이콘 컴포넌트로 렌더링한다.
- 하단 인디케이터는 XP가 아니라 마일스톤 레일의 `scrollLeft / (scrollWidth - clientWidth)` 비율을 나타낸다.
- 터치, 트랙패드, 드래그성 스크롤 및 좌우 방향키 이동이 모두 같은 인디케이터 상태를 갱신한다.

## 상태 모델

각 마일스톤은 `complete`, `currentLocked`, `locked` 중 하나의 표시 상태를 가진다.

- `complete`: 현재 지점보다 앞선 보상. 완료 아이콘을 표시한다.
- `currentLocked`: 현재 선택된 마일스톤이지만 아직 다음 해금 조건을 채우지 못한 보상. 현재 배지와 잠금 아이콘을 함께 표시한다.
- `locked`: 현재 지점보다 뒤에 있는 보상. 잠금 아이콘을 표시한다.

현재 화면의 두 번째 카드는 `currentLocked`로 취급한다. 첫 번째 카드는 완료, 나머지 카드는 잠금 상태다.

## 컴포넌트 동작

마일스톤 레일에 ref와 스크롤 진행 상태를 둔다. `scroll` 이벤트가 발생하면 실제 최대 스크롤 거리를 기준으로 0~1 진행률을 계산한다. 방향키 핸들러는 기존처럼 레일을 이동시키고, 발생한 스크롤 이벤트가 인디케이터를 갱신한다.

하단 인디케이터는 전체 트랙 위에서 움직이는 고정 비율의 활성 구간으로 표현한다. 활성 구간의 너비는 `clientWidth / scrollWidth`로 계산하고, 위치는 스크롤 진행률에 따라 트랙 안에서 이동한다. 콘텐츠가 넘치지 않으면 활성 구간은 트랙 전체를 채운다.

## 접근성

- 완료 및 잠금 아이콘은 텍스트 기반 `aria-label`을 유지한다.
- 장식용 아이콘 자체는 스크린리더에서 숨긴다.
- 레일은 기존 키보드 포커스와 좌우 방향키 조작을 유지한다.
- 인디케이터는 중복 정보를 전달하지 않도록 장식 요소로 유지한다.

## 테스트

- 현재 마일스톤에도 잠금 아이콘이 렌더링되는지 검증한다.
- 잠금 아이콘이 임시 인라인 SVG가 아니라 프로젝트 아이콘 컴포넌트를 사용하는지 검증한다.
- 레일 스크롤 이벤트가 진행 상태 갱신 함수에 연결되는지 검증한다.
- 인디케이터의 너비와 위치가 레일의 가시 비율 및 스크롤 비율에서 계산되는지 검증한다.
- 기존 고정 카드 너비, 마지막 카드 접근, 방향키 스크롤 회귀 테스트를 유지한다.
- 모바일 브라우저에서 처음, 중간, 끝 위치를 확인하고 콘솔 오류가 없는지 검증한다.

## 제외 범위

- 서버의 레벨 또는 보상 API 구조 변경
- 마일스톤 보상 목록의 콘텐츠 변경
- 다른 팬 성장 화면의 진행률 UI 변경
