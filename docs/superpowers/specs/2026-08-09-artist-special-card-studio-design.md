# Fanfolio 아티스트 스페셜 카드 스튜디오 설계

## 목적

아티스트와 소속사 담당자가 별도 교육 없이 포토카드에 사진, 손글씨, 보이스, 홀로그램 효과, 짧은 동영상을 결합하고 팬에게 공개될 결과를 검수 요청 전에 확인할 수 있게 한다.

이번 변경은 기존 아티스트 스튜디오의 디자인 체계와 정적 ES 모듈 구조를 유지한다. 백엔드에 이미 존재하는 `voiceAssetId`, `videoAssetId`, `designConfig`, `handwritingAssetId` 계약을 재사용하고, 서로 끊어진 편집·저장·미리보기·검수 흐름을 하나의 제작 경험으로 완성한다.

## 사용자와 핵심 과업

주 사용자는 운영팀이 발급한 전용 계정으로 접속하는 아티스트 또는 소속사 담당자다. 사용자는 다음 과업을 수행한다.

1. 스튜디오 홈에서 초안, 검수 중, 수정 요청, 공개 카드 현황을 파악한다.
2. 담당 아티스트와 캠페인을 선택하고 카드 제작 방식을 고른다.
3. 사진과 텍스트를 배치하고 손글씨, 보이스, 홀로그램, 동영상을 선택적으로 추가한다.
4. 팬 앱에서 보이는 카드 앞면·뒷면과 미디어 재생 상태를 확인한다.
5. 실제 자산 검증을 통과한 카드만 운영팀에 검수를 요청한다.
6. 검수 의견을 확인하고 수정한 뒤 다시 요청한다.

## 범위

### 포함

- 스튜디오 홈 대시보드
- 카드 제작 방식 선택
- 통합 비주얼 편집기
- 보이스 업로드와 브라우저 녹음
- 홀로그램 프리셋과 강도·각도 조절
- 짧은 동영상 파일 업로드와 카드 내 재생
- 직접 쓰기와 이미지 추출을 합친 손글씨 도구
- 팬 앱 형태의 통합 미리보기
- 데이터 기반 검수 체크리스트와 검수 메모 전송
- 초안 저장, 편집 재개, 검수 상태 표시
- 현재 감사에서 확인된 제작 이미지 저장 단절, 홈 이동, 빈 카탈로그 상태, 아이콘 배경 문제 수정

### 제외

- YouTube, TikTok, Instagram 등 외부 동영상 URL 임베드
- 다중 트랙 영상 편집, 키프레임, 자막 편집
- 음성 노이즈 제거와 전문 오디오 편집
- 아티스트 간 실시간 공동 편집
- 운영팀 이메일 발송 자동화

외부 동영상 링크는 서비스 정책과 임베드 제한, 링크 만료, 광고·추적 문제를 정리한 뒤 별도 기능으로 추가한다. 이번 MVP는 Fanfolio 저장소에 업로드한 짧은 파일만 지원한다.

## 경험 원칙

1. **한 화면에서 만든 결과가 다음 단계에서 사라지지 않는다.** 사진, 손글씨, 보이스, 동영상과 효과는 단일 카드 초안 상태를 사용한다.
2. **특수 기능은 선택 사항이다.** 기본 포토카드는 사진만으로 저장할 수 있고, 활성화한 특수 기능만 필수 검증한다.
3. **팬이 보는 결과를 먼저 보여준다.** 기술 필드명 대신 카드 위의 시각 효과와 실제 재생 컨트롤을 제공한다.
4. **저장 상태를 숨기지 않는다.** 저장 중, 저장 완료 시각, 오프라인, 저장 실패를 헤더에서 명확히 표시한다.
5. **검수 상태는 행동으로 연결한다.** 수정 요청 카드에는 운영팀 의견과 바로 편집 버튼을 함께 제공한다.

## 정보 구조

### 스튜디오 홈

로그인 후 첫 화면은 새 카드 폼이 아니라 대시보드다.

- 상단: 담당 아티스트·소속사 프로필, 알림, 새 카드 만들기
- 요약: 초안, 검수 중, 수정 요청, 공개 카드 수
- 작업 대기열: 최근 저장 카드, 운영팀 수정 요청, 공개 예정 카드
- 빠른 시작: 사인 카드, 홀로그램 카드, 모션 카드 레시피
- 활동: 최근 검수 결과와 카드 공개 기록

‘스튜디오 홈’과 검수 완료 화면의 ‘홈으로 이동’은 모두 이 대시보드로 이동한다.

### 제작 흐름

제작 흐름은 다음 다섯 단계로 보인다.

1. 제작 방식 선택
2. 카드 디자인
3. 카드 정보
4. 팬 앱 미리보기
5. 검수 요청

손글씨는 별도 페이지가 아니라 디자인 단계의 레이어 도구다. 보이스와 동영상도 카드 정보 폼 뒤에 숨기지 않고 디자인 단계의 ‘미디어’ 패널에서 추가한다.

## 통합 비주얼 편집기

기존의 왼쪽 도구 막대, 중앙 카드 캔버스, 오른쪽 속성 패널 구조를 유지한다.

### 도구

- 사진
- 레이아웃
- 텍스트
- 손글씨
- 보이스
- 모션
- 홀로그램
- 뒷면

아이콘은 문자·이모지 대신 프로젝트에서 사용하는 일관된 아이콘 라이브러리 또는 실제 이미지 자산을 사용한다. 현재 색상, 반경, 타이포그래피 토큰은 유지한다.

### 카드 캔버스

- 앞면·뒷면 전환
- 사진, 텍스트, 스티커, 손글씨 레이어 선택
- 드래그 이동, 크기·회전·투명도 조절
- 실행 취소·다시 실행
- 확대·축소
- 모션과 홀로그램 재생 일시 정지
- 모션 감소 환경에서는 정적 포스터와 낮은 강도의 효과 사용

## 특수 기능

### 보이스 스튜디오

보이스는 업로드와 브라우저 녹음 두 방식으로 추가한다.

- 지원 파일: MP3, M4A/MP4 오디오, WAV
- 권장 길이: 3초 이상 30초 이하
- 최대 길이: 60초
- 기능: 녹음 시작·정지, 파일 교체, 재생, 삭제, 시작·종료 지점 선택
- 표시: 파일명 또는 녹음 이름, 길이, 업로드 상태, 파형 또는 진행 막대
- 팬 미리보기: 사용자가 재생 버튼을 눌렀을 때만 재생

브라우저 자동 재생 제한을 피하기 위해 음성은 사용자 동작 없이 재생하지 않는다. `hasVoice=true`인 경우 `voiceAssetId`가 없으면 저장은 가능하지만 검수 요청은 차단한다.

### 홀로그램 랩

홀로그램은 서버 이미지에 효과를 구워 넣는 대신 `designConfig.front.effect`와 관련 값을 저장하고 스튜디오와 팬 앱에서 동일하게 렌더링한다.

프리셋은 다음 네 가지다.

- 오로라: 부드러운 다색 광택
- 프리즘: 강한 무지개 분광
- 크리스털: 얇고 선명한 포일 빛줄기
- 스타더스트: 점광과 반짝임

사용자는 강도와 각도를 조절하고 움직임을 켜거나 끌 수 있다. 포인터가 있는 환경에서는 카드 기울기에 따라 빛 방향이 변하고, 터치·키보드·모션 감소 환경에서는 정해진 애니메이션 또는 정적 효과를 사용한다.

`designConfig.front`의 확장 필드는 다음과 같다.

```json
{
  "effect": "holographic",
  "effectPreset": "aurora",
  "effectIntensity": 0.78,
  "effectAngle": 135,
  "effectMotion": true
}
```

### 모션 카드

모션 카드는 외부 링크가 아니라 MP4 또는 WebM 파일을 업로드한다.

- 권장 길이: 3초 이상 15초 이하
- 최대 길이: 30초
- 영상은 기본적으로 음소거·반복 재생한다.
- 보이스 자산과 영상 원음은 별개다.
- 업로드 후 첫 프레임 또는 사용자가 선택한 시점을 포스터로 사용한다.
- 카드 미리보기에는 재생·일시 정지, 음소거 상태, 길이를 표시한다.
- 팬 앱에서는 카드 상세를 연 뒤 사용자가 재생한 경우에만 모션을 활성화한다.

모션 카드가 꺼져 있거나 비디오 로딩에 실패하면 정적 카드 이미지와 홀로그램 효과가 그대로 남아야 한다.

### 통합 손글씨

직접 그리기와 이미지 업로드는 같은 손글씨 레이어를 갱신한다.

- 직접 그리기: 즉시 투명 PNG로 카드에 배치하며 배경 제거 요청을 보내지 않는다.
- 이미지 업로드: 자르기, 대비 조절, 지우기·복원 후 배경 제거 작업을 요청한다.
- 처리 중에도 원본 미리보기와 진행 상태를 보인다.
- 완료 후 실제 카드 위에서 위치, 크기, 회전, 투명도를 조절한다.

기존 `state.signature`와 `state.editor.signatureSrc`의 이중 상태를 제거하고 편집기 상태 하나만 사용한다.

## 카드 정보와 카탈로그 상태

카드 정보 화면은 편집기에서 선택한 카드 이미지와 미디어를 그대로 이어받는다. 같은 이미지 파일을 다시 고르게 하지 않는다.

- 담당 아티스트가 없으면 빈 선택창 대신 ‘운영팀에서 담당 아티스트를 배정해야 합니다’ 상태와 문의 경로를 표시한다.
- 아티스트를 선택하면 해당 멤버만 표시한다.
- 카드 이미지, 손글씨, 보이스, 동영상의 업로드 상태를 요약한다.
- 활성화하지 않은 특수 기능은 검증 대상에서 제외한다.

## 팬 앱 미리보기

검수 전 미리보기는 단순 렌더링 이미지가 아니라 팬 앱 카드 상세 형태로 제공한다.

- 카드 앞면·뒷면
- 홀로그램 효과와 모션 감소 상태
- 모션 재생·일시 정지
- 보이스 재생과 길이
- 손글씨 레이어
- 카드명, 아티스트, 멤버, 희귀도, 발행 수량

서버가 만든 정적 `previewImageUrl`은 공유 가능한 대표 이미지로 유지하고, 동적 미디어는 `layers.video`, `layers.voice`, `layers.effects` 응답으로 재생한다.

## 저장과 데이터 흐름

### 초안 상태

브라우저 메모리는 즉각적인 편집 반응과 실행 취소에만 사용한다. 영속 초안은 카드 생성·수정 API에 저장한다.

1. 사용자가 파일을 선택하거나 녹음을 끝낸다.
2. 스튜디오가 `/uploads/presign`으로 자산 업로드 위치를 받는다.
3. 파일을 업로드하고 `assetId`를 카드 초안에 연결한다.
4. 효과와 레이어 값은 `designConfig`로 저장한다.
5. 헤더에 저장 중, 저장 완료 시각 또는 저장 실패를 표시한다.
6. 재접속 시 `/artist/cards/{id}` 응답으로 편집 상태를 복원한다.

사진 편집기에서 고른 로컬 이미지가 아직 업로드되지 않았다면 카드 정보 단계로 이동하기 전에 자동 업로드한다. 업로드 실패 시 입력값을 유지하고 재시도 버튼을 제공한다.

### API 변경

기존 카드·업로드 API를 우선 재사용한다. 필요한 계약 확장은 다음으로 제한한다.

- `designConfig.front.effectPreset`
- `designConfig.front.effectMotion`
- `designConfig.video.posterTime`
- `designConfig.video.loop`
- `designConfig.voice.trimStart`
- `designConfig.voice.trimEnd`
- 검수 요청 body의 `reviewNote`

검수 메모는 카드의 최신 검수 요청과 연결해 저장한다. 관리자 카드 상세 응답에서 메모를 확인할 수 있어야 한다.

## 검수 규칙

검수 체크리스트는 문구가 아니라 실제 데이터로 계산한다.

- 카드 이미지 자산이 존재한다.
- 아티스트와 멤버가 유효하다.
- 보이스 사용 시 `voiceAssetId`가 존재하고 업로드가 완료됐다.
- 모션 사용 시 `videoAssetId`가 존재하고 업로드가 완료됐다.
- 손글씨 사용 시 처리 완료 자산이 존재한다.
- 발행 수량이 유효하다.
- 팬 앱 미리보기를 한 번 이상 열었다.

검수 요청 후 상태는 `pending_review`가 되며 일반 편집은 잠근다. 사용자는 검수 요청 취소가 허용된 경우에만 초안으로 되돌릴 수 있다. ‘언제든 임시 저장 카드에서 수정’과 같은 실제 상태와 다른 안내는 제거한다.

## 오류와 복구

- 미디어 업로드 실패: 해당 패널에 원인과 재시도 버튼 표시
- 업로드 중 페이지 이동: 이동 전 확인, 업로드 완료 후 자동 저장
- 세션 만료: refresh 쿠키로 한 번 갱신 후 현재 편집 상태를 유지한 채 로그인 안내
- 카탈로그 없음: 제작 폼을 비활성화하고 운영팀 배정 안내
- 동영상 재생 실패: 정적 포스터와 다시 시도 제공
- 홀로그램 성능 저하: 자동으로 모션을 끄고 정적 효과 유지
- 배경 제거 실패: 원본 손글씨를 유지하고 다시 요청 또는 직접 지우기 제공

## 접근성

- 모든 아이콘 버튼에 기능을 설명하는 접근 가능한 이름을 제공한다.
- 도구 활성 상태는 색상뿐 아니라 `aria-pressed` 또는 현재 상태 텍스트로 전달한다.
- 보이스 녹음과 업로드 상태는 `aria-live` 영역에서 알린다.
- 슬라이더에는 레이블, 현재 값, 키보드 조작을 제공한다.
- 캔버스 레이어 위치는 키보드 화살표와 숫자 입력으로도 조정할 수 있다.
- 모션 감소 설정에서는 반복 홀로그램과 동영상 자동 재생을 중단한다.
- 오류는 색상만으로 표시하지 않고 해당 필드와 연결한다.

## 코드 구조

현재 `builder_app/app.js`는 로그인, API, 탐색, 카드 편집, 미디어 업로드, 검수 화면과 중복 이벤트 처리를 한 파일에서 담당한다. 이번 기능과 직접 관련된 경계만 분리한다.

- `builder_app/app.js`: 앱 초기화와 화면 라우팅
- `builder_app/studio-state.js`: 카드 초안 상태, 정규화, 검수 가능 여부
- `builder_app/studio-api.js`: 아티스트 카드·업로드·검수 API
- `builder_app/card-editor.js`: 편집기 렌더링과 레이어 조작
- `builder_app/media-tools.js`: 보이스 녹음·재생, 동영상 업로드·재생, 자산 상태
- `builder_app/studio-views.js`: 홈, 카드 목록, 설정, 검수 화면

새 빌드 도구나 프레임워크를 추가하지 않고 브라우저 ES 모듈을 사용한다. 순수 상태 변환과 검수 규칙은 DOM 없이 Node 테스트에서 실행할 수 있게 한다.

## 테스트 전략

구현은 실패하는 테스트를 먼저 추가한 뒤 최소 코드로 통과시킨다.

### 프론트 단위·계약 테스트

- 편집기 로컬 이미지가 카드 저장 전에 업로드 대상으로 변환된다.
- 직접 손글씨와 업로드 손글씨가 동일한 상태 필드를 사용한다.
- 보이스 사용 상태에서 자산이 없으면 검수할 수 없다.
- 모션 사용 상태에서 자산이 없으면 검수할 수 없다.
- 홀로그램 프리셋과 강도·각도가 `designConfig`에 저장되고 복원된다.
- 검수 메모가 submit-review 요청 body에 포함된다.
- 홈 탐색과 검수 완료 버튼이 대시보드 상태로 이동한다.
- 카탈로그가 비었을 때 카드 생성 입력을 노출하지 않는다.

### 백엔드 계약 테스트

- 지원되는 오디오·비디오 형식만 업로드 요청할 수 있다.
- 소유하지 않은 미디어 자산을 카드에 연결할 수 없다.
- 보이스·비디오·홀로그램 설정이 카드 생성·수정·미리보기·팬 상세까지 보존된다.
- 검수 메모가 관리자 검수 상세에서 조회된다.
- 활성화된 특수 기능에 필요한 자산이 없으면 검수 요청을 거부한다.

### 브라우저 검증

1. 아티스트 로그인과 세션 복원
2. 대시보드에서 모션 카드 시작
3. 사진·손글씨·홀로그램 적용
4. 보이스 녹음 또는 업로드와 재생
5. 동영상 업로드와 반복 재생
6. 카드 정보 저장과 재접속 복원
7. 팬 앱 형태 미리보기
8. 검수 메모 포함 요청
9. 검수 완료 뒤 홈 대시보드 이동
10. 모바일·태블릿·데스크톱 주요 폭과 모션 감소 상태

## 완료 조건

- 사진, 손글씨, 보이스, 동영상, 홀로그램 설정이 한 카드 초안에 저장되고 재접속 후 복원된다.
- 팬 앱 미리보기에서 보이스와 동영상이 실제 사용자 동작으로 재생된다.
- 홀로그램 효과가 스튜디오와 팬 앱에서 같은 프리셋·강도·각도로 보인다.
- 활성화한 특수 기능의 자산이 없으면 검수 요청이 차단된다.
- 검수 메모가 관리자에게 전달된다.
- 검수 완료 후 스튜디오 홈 대시보드로 이동한다.
- 자동화 테스트와 전체 백엔드 계약 테스트가 통과한다.
- 브라우저에서 핵심 제작 흐름을 직접 완료하고 시각적 결함을 확인한다.
