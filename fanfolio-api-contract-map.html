Fanfolio API 계약 맵

프론트가 기대하는 HTTP 경계와 백엔드 계약 테스트를 한 화면에서 확인합니다. API를 선택하면 입력, 응답, 오류, 연결된 테스트를 볼 수 있습니다.

MVP · v0.2정본: BACKEND_IMPLEMENTATION_CONTRACT.md테스트: backend/tests/contract
현재 상태: 맵의 288개 HTTP 경로는 계약 테스트로 구현·검증됩니다. Health → Fixture → Auth → Fan → Admin → Artist 순서로 테스트를 읽으면 각 기능 경계를 따라갈 수 있습니다.

경계 규칙

Fan

로그인한 팬만 카드 코드/QR을 등록하고, 본인이 소유한 카드와 프로필·알림을 조회·변경합니다.

Admin

루트 관리자는 파트너 기업·담당자·전체 공개를 관리하고, 기업 관리자는 배정된 아티스트와 카드만 관리합니다. Artist는 Admin API에 접근할 수 없습니다.

Artist

템플릿 기반 특별 카드를 초안으로 만들고 검수 요청합니다. 공개 권한은 Admin에게만 있습니다.

Test fixture (test only)

APP_ENV=test에서만 상태 초기화·시드 데이터를 제공합니다. production에 노출하면 안 됩니다.

실행: cd backend && APP_ENV=test .venv/bin/pytest tests/contract -q · 이 화면은 빠른 탐색용이고, 세부 기준은 계약 문서와 계약 테스트를 따릅니다.
