## 확인하지 않은 범위

- iOS/Android 실기기, 카메라·센서·OS 푸시 권한
- Firebase 실자격증명 기반 백그라운드 푸시 전달
- 실제 PostgreSQL/Redis/SMTP/오브젝트 스토리지 장애 및 백업 복원 훈련

계정 삭제는 실제 QA 계정에서 실행하지 않고 격리된 테스트 데이터로만 확인했다. 카드 전체 흐름의 브라우저 증거는 `.tmp-full-scenario-fan-registration.png`에 보관되어 있다. 관리자 카드 운영 화면의 공개 일정 패널과 카드 검수 영역은 기존 로그인 세션으로 브라우저 렌더링을 확인했다. 이후 스키마 불일치로 발생한 `users.deleted_at` 500은 0064~0066 마이그레이션을 로컬 DB에 적용하고 백엔드를 재기동해 해소했으며, 재기동 후에는 로컬 부트스트랩 계정이 없어 관리자 재로그인 상태까지는 재현하지 못했다. 백엔드 헬스·레디니스와 비인증 API 경계는 재기동 후 확인했다.

## 2026-08-28 최신 로컬 회귀 보정

- 관리자 운영 화면의 공개 일정 입력을 카드·이벤트·상품 유형별 콘텐츠 목록과 연결하고, 유형 변경 시 선택 가능한 콘텐츠 목록을 갱신하도록 보완했다. 별도 캘린더 페이지는 만들지 않고 기존 카드 운영 화면에 통합했다.
- 관리자 단일 선택 입력을 공통 콤보박스로 통일했다. 이벤트 연결 대상, 카드 등급, 캠페인 아티스트, 업적의 카드·캠페인·드롭, 팬 패스 프리셋이 동일한 키보드·폼 값 계약을 사용한다. 캠페인의 다중 카드 선택은 다중 선택 의미를 보존하기 위해 유지했다.
- 카드 운영 미리보기의 카드·팩·발급 필터와 생성 폼, 통계 미리보기의 파트너·아티스트·카드팩 필터도 동일한 공통 콤보박스로 통일했다. 필터 변경은 기존 상태와 재렌더링 계약을 유지하며 생성 폼은 hidden form value로 제출된다.
- 데모 카탈로그의 프론트 전용 `/src/assets/...` 경로를 백엔드가 실제로 제공하는 `/assets/...` 경로로 교정했다. 새 데모 부트스트랩에서 아티스트 이미지가 실제 HTTP 200 이미지인지 확인하는 회귀 검증도 추가했다.
- 관리자 잔여 네이티브 선택창은 다중 선택, 반응형 파트너 전환, 정적 미리보기 전용으로 분류했다. 운영 단일 선택 입력은 공통 콤보박스 계약으로 통일되어 있다.
- 관리자 다중 선택 입력도 공통 콤보박스로 보완했다. 컬렉션 특전 캠페인의 필수 카드와 업적의 보상 선택은 체크 상태·선택 개수·폼 hidden 값을 함께 유지하며, 기존 다중 값 API 계약을 보존한다.
- 카드 상세의 가로 스와이프 전환을 실제 상세 경로에 활성화했다. 세로 스크롤은 유지하고, 가로 이동량이 기준을 넘을 때만 앞면·뒷면을 전환하도록 공통 인터랙티브 카드 계약과 회귀 검증을 연결했다.

### 운영 인증 smoke 게이트 보완

운영 자격증명을 저장소에 넣거나 브라우저 자동화 세션을 새로 만들지 않고도 배포 후 인증 계약을 반복 확인할 수 있도록 `scripts/hosted-auth-smoke.sh`를 추가했다. 팬·관리자·아티스트 로그인과 각 역할의 읽기 전용 프로필/관리자 컨텍스트/성장 API를 확인하며, 자격증명이 없을 때는 기본적으로 `DEFERRED`(종료 코드 2)로 종료하고 CI 수동 작업에서는 `HOSTED_SMOKE_REQUIRED=1`로 실패 처리한다. 실제 자격증명을 사용한 성공 증거가 생기기 전까지 운영 게이트를 완료로 올리지 않는다.

백업·복원 항목에는 `scripts/backup-restore-verify.sh`를 추가했다. PostgreSQL 백업 아카이브의
가독성을 확인하고, 명시적으로 격리 확인 문자열을 제공한 경우에만 schema-only 복원 리허설을
실행한다. 데이터베이스 생성·삭제·초기화는 수행하지 않으며, 실제 운영 백업 복원 증적은 여전히
별도 확보가 필요하다.

## 병합 후 호스팅 검증 보정

실제 배포 기준을 Render·Vercel·Supabase·Cloudflare R2·Resend·Firebase로 정정했다. Compose는 현재 배포 경로의 출시 게이트가 아니다.

- `https://fanfolio-api.onrender.com/api/health`: 콜드스타트 약 60초 후 `200`, `{"status":"healthy"}`.
- `https://fanfolio-fan.vercel.app/`: `200`, 실제 인증 팬 홈과 이벤트·아티스트·카드 콘텐츠 렌더링 확인.
- `https://fanfolio-admin-one.vercel.app/`: `200`, 관리자 로그인 화면 렌더링 확인. 로컬 bootstrap 계정은 호스팅 DB에 존재하지 않아 로그인 실패.
- `https://fanfolio-studio.vercel.app/`: `200`, 실제 스튜디오 세션으로 홈 렌더링 확인.
- Vercel 팬앱·관리자·스튜디오의 `/api/health` 프록시: 모두 `200`.

남은 호스팅 검증은 관리자 운영 계정으로 실제 로그인하는 단계와 Supabase/R2/Resend/Firebase의 자격증명 기반 기능 호출이다. 해당 계정·서비스 자격증명을 코드나 로컬 테스트 계정으로 대체해 통과 처리하지 않는다.
