# Demo catalog

The demo catalog is the visual source of truth for screenshots, preview routes,
and the idempotent hosted catalog seed. `dreamscape-character-bible.json`
defines the group, member IDs, fixed visual traits, and the asset filenames.

Member identity and the group composition are invariant. Campaign artwork may
change the outfit, pose, lighting, background, and card frame only. User data is
not part of this catalog and must never be reset by the seed.
