# Fanfolio 운영 우선순위 P6–P10 구현 기록

## 기준

`docs/audits/platform-operations-audit-2026-08-25.md`의 관리자 운영 우선순위를 기준으로, 팬 앱 기능을 운영 가능한 큐와 통제면으로 확장한다.

## 구현 상태

- [x] P6 운영 대시보드: 실패 전달·재시도·CS·거래·환불·보상 큐 요약과 최근 감사 조치
- [x] P7 팬 360도: 루트 관리자 전용 계정·포인트·카드·주문·거래·CS·알림 타임라인
- [x] P8 CS/분쟁: 담당자 지정, 구조화 근거, 거래 보류, 환불·포인트 조정 승인 요청
- [x] P9 상품 운영: 재고, 판매량, 1인 한도, 예약 공개 시각, 노출 슬롯, 팬 세그먼트 계약과 구매 차단
- [x] P10 이중 승인: 승인 요청 생성·조회·승인·반려, 요청자 자기 승인 차단, 감사 로그, 승인 후 포인트 조정·환불 집행

## 검증 경계

- 계약·단위·마이그레이션 테스트와 관리자 JavaScript 계약 테스트로 로컬 동작을 검증한다.
- 실제 Firebase/Resend/R2 외부 전송, 브라우저 파일 업로드, 배포 환경의 운영자 계정·도메인·시크릿은 별도 운영 게이트다.
- 팬 개인정보와 전달 목적지는 관리자 응답에서 최소화하며, 팬 360은 루트 관리자 권한으로 제한한다.
