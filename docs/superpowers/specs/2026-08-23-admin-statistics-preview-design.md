# 관리자 통계 프리뷰 디자인

## 목표

현재 Fanfolio 관리자 웹의 네이비 사이드바, 보라색 강조색, 흰색 패널 체계를 유지하면서 ROOT 운영 관리자와 파트너 관리자에게 서로 다른 범위의 통계를 보여 주는 조작 가능한 프리뷰를 제공한다.

## 범위

- 로컬 전용 `?preview=statistics` 진입점을 추가한다.
- 프리뷰 데이터만 사용하며 운영 API나 실제 관리자 상태를 변경하지 않는다.
- ROOT/파트너 보기 전환, 조회 기간 전환, 파트너·아티스트·카드팩 필터를 제공한다.
- 화면 폭에 따라 데스크톱 대시보드에서 단일 열 모바일 레이아웃으로 재배치한다.

## 정보 구조

### ROOT 통계

- 전체 파트너, 활성 팬, 카드 발급, 카드팩 개봉 KPI
- 기간별 팬 성장과 카드팩 개봉 추이
- 카드팩 성과 순위와 공개 확률 대비 실제 발급 비율
- 발급부터 컬렉션 등록까지의 전환 퍼널
- 실패·이상 징후 모니터링

### 파트너 통계

- 파트너 범위의 활성 팬, 카드 발급, 개봉, 컬렉션 등록 KPI
- 소속 아티스트별 팬 활동 추이
- 카드팩별 개봉·등록 성과
- 컬렉션 완성도와 희귀도별 보유 분포
- 공개 확률과 실제 발급 비율 비교

## 상호작용

- `ROOT 전체`와 `파트너 보기` 세그먼트로 대시보드 범위를 전환한다.
- 7일, 30일, 90일 기간 선택에 따라 KPI와 차트 데이터가 즉시 갱신된다.
- 파트너/아티스트/카드팩 필터는 해당 화면의 레이블과 표 데이터를 갱신한다.
- 기간 비교 토글은 차트에 이전 기간 기준선을 노출한다.

## 구현 경계

- `admin_app/app.js`에 프리뷰 상태, 정적 데이터, SVG 차트 생성기와 이벤트 바인딩을 둔다.
- `admin_app/styles.css`에 `statistics-preview` 네임스페이스 스타일을 추가한다.
- `admin_app/tests/admin-statistics-preview.test.mjs`에서 진입점, 두 역할, 필터, 핵심 위젯, 반응형 스타일을 검사한다.

## 오류와 빈 상태

- 필터 결과가 없으면 표 대신 명시적인 빈 상태를 보여 준다.
- 차트는 숫자가 0이어도 높이 계산이 깨지지 않도록 최소 기준값을 사용한다.
- 프리뷰는 외부 요청을 하지 않으므로 네트워크 오류 상태는 포함하지 않는다.
