# 관리자 파트너 로고 및 운영 기능 설계

## 목표

관리자 웹의 파트너 디렉터리를 목표 이미지와 같은 운영 도구로 완성한다. 파트너 회사 로고는 선택적으로 등록하고, 파트너 목록과 상세 화면에서 일관되게 표시한다. 동시에 파트너 등록부터 관리자·아티스트 배정까지 핵심 흐름이 실제 API와 연결되어 동작하는지 자동화 테스트로 검증한다.

## 파트너 로고 정책

- 신규 파트너 등록과 기존 파트너 수정 화면에서 로고를 선택적으로 업로드한다.
- PNG, JPG, WebP만 허용하며 파일 크기는 2MB 이하로 제한한다.
- 선택 직후 정사각형 프레임 안에 실제 미리보기를 표시한다.
- 이미지는 잘라내지 않고 `object-fit: contain`으로 전체 로고와 투명 여백을 보존한다.
- 로고가 없거나 불러오기에 실패하면 기업명의 첫 글자를 표시한다.
- 기존 로고는 수정 화면에서 교체하거나 제거할 수 있다.

## 저장 구조와 데이터 흐름

1. 관리자가 로고 파일을 선택한다.
2. 프론트가 파일 형식과 크기를 검증하고 로컬 미리보기를 표시한다.
3. 저장 시 기존 자산 업로드 API를 `organization_logo` 목적으로 호출한다.
4. 업로드 완료 후 받은 자산 ID를 파트너 생성 또는 수정 API에 전달한다.
5. 백엔드는 자산이 존재하고 업로드가 완료됐으며 요청 관리자에게 허용된 자산인지 검증한다.
6. 파트너 응답은 같은 출처에서 사용할 수 있는 `logoUrl`을 반환한다.
7. 목록은 44px, 상세는 96px 정사각형 프레임으로 로고를 렌더링한다.

기존 `logoUrl` 문자열 입력 방식은 관리자 UI에서 노출하지 않는다. API는 `logoAssetId`를 기준으로 자산을 검증하며, 과거 데이터의 `logoUrl`은 읽기 호환성을 위해 유지한다.

## 관리자 UI

### 등록·수정 서랍

- 상단에 로고 업로드 영역과 정사각형 미리보기를 배치한다.
- 빈 상태에는 업로드 아이콘, 권장 규격, 지원 형식을 표시한다.
- 파일 선택 후 파일명과 교체·제거 동작을 제공한다.
- 로고 업로드 실패와 파트너 저장 실패를 서로 다른 오류로 표시한다.
- 로고 없이 저장하는 경우 별도 경고 없이 기업명 첫 글자 폴백을 사용한다.

### 파트너 목록과 상세

- 목록 항목에는 로고, 기업명, 상태, 연결된 아티스트·관리자 수를 표시한다.
- 상세 헤더에는 확대된 로고, 기업명, 상태, 계약 기간, 담당자, 발행 카드 수, 최근 수정일을 표시한다.
- 이미지가 깨지면 즉시 첫 글자 폴백으로 전환한다.

## 핵심 운영 기능 검증 범위

다음 흐름을 API 계약 테스트와 관리자 프론트 회귀 테스트로 검증한다.

1. 파트너 생성, 중복 코드 처리, 수정, 활성·중지 전환
2. 로고 없음·업로드 성공·잘못된 형식·초과 용량·깨진 이미지 폴백
3. 파트너 검색, 상태 필터, 선택 및 상세 조회
4. 파트너에 아티스트 연결·해제
5. 기업 관리자 발급과 임시 비밀번호 표시
6. 관리자 역할 변경, 활성·비활성 전환, 담당 아티스트 배정
7. 파트너 관리자가 다른 파트너 데이터에 접근하지 못하는 권한 경계
8. 운영 동작이 감사 로그에 남는지 확인

## 오류 처리

- 로고 업로드가 실패하면 파트너 저장 요청을 보내지 않는다.
- 파트너 저장이 성공하고 목록 갱신만 실패하면 저장 성공 상태를 유지한다.
- 409 중복 코드는 기존 파트너 목록을 다시 불러오고 구체적인 안내를 표시한다.
- 자산이 없거나 업로드 미완료이면 백엔드는 안정적인 오류 코드로 거절한다.
- 이미지 렌더링 오류는 전체 화면 오류로 승격하지 않고 해당 로고만 폴백 처리한다.

## 테스트와 완료 기준

- 새로운 동작은 실패하는 테스트를 먼저 추가한 뒤 구현한다.
- 백엔드 파트너 계약 테스트, 자산 업로드 테스트, 관리자 앱 테스트를 통과한다.
- JavaScript 구문 검사, Ruff 포맷·린트, 프론트 린트를 통과한다.
- 데스크톱과 좁은 화면에서 가로 스크롤 없이 동작한다.
- 목표 이미지와 실제 관리자 화면을 같은 상태로 캡처해 비교하고 P0·P1·P2 시각 문제를 해결한다.
- 배포 후 로고 등록, 목록 표시, 상세 표시, 교체·제거의 핵심 경로를 실제 브라우저에서 확인한다.

## 제외 범위

- 로고 수동 크롭 및 확대·이동 편집
- 기업별 다크·라이트 로고 두 벌 관리
- 외부 URL 직접 입력
- 계약 문서나 사업자등록증 업로드
