# Compact Inventory Source Chips Design

## Scope

팬 컬렉션 상단의 아이템 출처 선택 영역만 참조 이미지에 맞춰 압축한다. 컬렉션 제목, 상태 필터, 아이템 카드와 하단 내비게이션은 변경하지 않는다.

## Layout

- 출처 선택은 한 줄 가로 스크롤 칩으로 유지한다.
- 칩 높이는 46px, 아티스트 로고는 28px로 축소한다.
- 아티스트 출처는 로고, 이름, 개수 배지를 한 줄에 표시한다.
- 전체 레벨은 로고 없이 이름과 개수 배지만 표시한다.
- `아이템 N` 보조 문구는 제거한다.
- 선택 상태는 연한 보라 배경과 1px 보라 테두리로 표현한다.

## Data and behavior

- 기존 출처 그룹, 선택 상태, 필터 초기화 동작은 유지한다.
- `artistLogoUrl`이 없으면 아티스트명 첫 글자 폴백을 유지한다.
- 전체 레벨 데이터 분리와 아이템 개수 계산은 변경하지 않는다.

## Verification

- 회귀 테스트에서 전체 레벨 로고가 렌더링되지 않는지 확인한다.
- 컴팩트 높이, 로고 크기, 개수 배지 스타일을 확인한다.
- 동일한 미리보기 상태로 참조 이미지와 구현 화면을 비교한다.
