# 팬레벨 참고 화면 재구현 설계

## 목표

제공된 모바일 참고 이미지의 팬레벨 화면을 현재 Fanfolio 팬 앱에 최대한 동일하게 재현한다. 실제 API 데이터의 레벨, XP, 업적 수와 문구가 참고 이미지와 달라도 화면의 크기, 간격, 타이포그래피, 색상, 카드 구조와 시각적 위계는 참고 이미지를 우선한다.

## 선택한 접근

기존 `FanGrowth` 컴포넌트를 참고 화면의 정보 구조로 전면 재구성한다. 별도 화면을 복제하거나 CSS만 덧씌우지 않고, 현재 `/me/progression` 데이터와 보상 수령·장착 기능을 유지한 채 마크업과 전용 스타일을 정리한다.

## 화면 구조

1. 브랜드 헤더: `FANFOLIO`, 알림 버튼, 프로필 이미지
2. 제목 영역: `팬 레벨`과 안내 문구
3. 현재 레벨 카드: 원형 XP 진행도, 레벨·등급·XP, 다음 레벨 안내, 혜택 보기 버튼
4. 미션: 최대 3개 업적을 아이콘, 제목, 설명, 완료 또는 수치 진행도로 표시
5. 레벨 마일스톤: 이전·현재·다음 단계 보상을 가로 스크롤 카드로 표시
6. 나의 레벨 혜택: 아티스트 이미지와 현재 레벨 혜택 목록
7. 고정 하단 메뉴: 탐색, 보관함, 홈, 팬 레벨, 마이

## 데이터 매핑

- 현재 레벨과 XP는 `progression.level`을 사용한다.
- 원형 진행률은 현재 누적 XP와 `nextLevelXp`로 계산한다.
- 미션은 `progression.achievements`에서 최대 3개를 사용하며, 완료 시 `완료`, 미완료 시 `currentValue / targetValue`를 표시한다.
- 실데이터가 부족한 마일스톤과 혜택 설명은 화면 구성을 안정적으로 유지하는 프레젠테이션 메타데이터로 보완한다. 서버가 확정하는 XP·보상 권한은 변경하거나 위조하지 않는다.
- 보상 수령, 팬 패스, 장착 패널은 기존 동작을 유지하며 참고 화면의 `전체 보기`와 혜택 버튼을 통해 접근한다.

## 시각 기준

- 기준 뷰포트는 참고 이미지 비율에 맞춘 모바일 폭 430px이다.
- 화면 배경은 거의 흰색인 옅은 라벤더, 기본 글자는 짙은 네이비, 강조색은 보라·파랑 계열을 사용한다.
- 한글은 현재 앱의 한국어 폰트 스택을 사용하되 참고 이미지와 가까운 굵기와 자간을 적용한다.
- 카드 테두리는 옅은 라벤더 1px, 큰 반경, 매우 약한 보라색 그림자를 사용한다.
- 원형 진행도, 카드 높이, 섹션 간격, 하단 메뉴 크기는 참고 이미지의 비율을 우선해 조정한다.
- 좁은 화면에서도 레벨 카드의 핵심 정보가 찌그러지지 않도록 축소하되 구조와 순서는 유지한다.

## 이미지와 아이콘

- 참고 이미지의 혜택 카드 사진과 가까운 기존 프로젝트 아티스트 자산을 우선 재사용한다.
- 알림, 미션, 마일스톤, 하단 메뉴 아이콘은 현재 프로젝트의 아이콘 컴포넌트 또는 설치된 아이콘 패턴을 재사용한다.
- 장식용 CSS 도형이나 이모지는 새로 만들지 않는다.

## 상태와 접근성

- 로딩, 전체 오류, 부분 오류, 보상 수령 중, 저장 중 상태를 유지한다.
- 버튼에는 접근 가능한 이름과 키보드 포커스 스타일을 제공한다.
- 진행률은 시각적 원형 그래프와 함께 읽을 수 있는 레이블을 제공한다.
- 가로 마일스톤은 터치 스크롤과 키보드 접근을 지원한다.

## 검증

- `FanGrowth` 동작 계약 테스트를 참고 화면의 새 구조에 맞게 보강한다.
- 프론트엔드 테스트, 린트, 타입 검사와 프로덕션 빌드를 실행한다.
- 로컬 앱을 430px 모바일 뷰포트로 캡처하고 원본 참고 이미지와 나란히 비교한다.
- 크기, 간격, 폰트, 색상, 정렬, 스크롤과 고정 내비게이션의 P0~P2 차이를 수정한 뒤 `design-qa.md`에 통과 결과를 기록한다.

## 범위 제외

- 백엔드 XP 정책과 레벨 계산 규칙 변경
- 참고 이미지의 고정 숫자를 실제 사용자 데이터 대신 강제로 표시하는 행위
- 새로운 인증, 결제, 랭킹 또는 소셜 기능
- 팬레벨 화면과 무관한 기존 화면 리팩터링
