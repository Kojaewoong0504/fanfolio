# 카드 컬렉션 저장소 디자인

## 목표

보관함의 최근 수집 카드는 최근 획득 내역만 빠르게 보여주고, 카드팩별 수집 현황과 정렬·필터·카드 관리는 별도 `카드 컬렉션` 화면에서 제공한다.

## 정보 구조

- 아티스트: 드림스케이프
- 컬렉션 그룹: 관리자가 지정하는 표시명. 목업은 `정규 1집 · DREAMSCAPE`를 사용한다.
- 카드팩: 한 컬렉션 그룹 안에 `Nebula Ver.`, `Starlight Ver.`, `Midnight Ver.`를 둔다.
- 카드: 카드팩별 번호, 희귀도, 보유 수량, 미획득 상태를 표시한다.

## 화면과 동작

- `/collection/cards`에서 전용 화면을 연다.
- 상단 뒤로가기는 `/collection`로 돌아간다.
- 컬렉션 그룹 선택기에는 그룹명과 전체 진행률을 표시한다.
- 카드팩 레일에서 팩을 선택하면 제목, 진행률, 카드 도감이 함께 바뀐다.
- 정렬 선택과 필터 패널은 전용 화면에서만 제공한다.
- 보관함의 `최근 수집 카드`에는 정렬·필터를 두지 않고 `전체 보기`로 전용 화면에 진입한다.
- 카드 클릭은 기존 카드 상세 동선을 재사용한다.

## 시각 기준

- 선택 시안의 430px 모바일 밀도와 4열 카드 도감을 따른다.
- 기존 Fanfolio의 보라색, 흰 배경, 고정 하단 내비게이션, 아이콘과 카드 이미지를 재사용한다.
- 카드팩 이미지는 별도 가짜 도형을 만들지 않고 기존 공식 목업 카드 뒷면 자산을 사용해 버전 색상으로 구분한다.
